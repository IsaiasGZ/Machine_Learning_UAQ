\section{Introducción}
El mercado financiero genera grandes volúmenes de datos de manera continua, 
lo que lo convierte en un campo de estudio ideal para la aplicación de 
técnicas de aprendizaje automático. La predicción de precios bursátiles 
representa uno de los problemas más estudiados en este ámbito, debido a 
su relevancia tanto para inversores individuales como para instituciones 
financieras.

En este trabajo se aplica un modelo de Regresión Lineal para predecir 
los precios históricos de la empresa Intel Corporation (INTC), utilizando 
datos horarios obtenidos a través de la API de Yahoo Finance para el 
período comprendido entre el 1 de enero de 2025 y el 1 de enero de 2026. 
Se analizan las columnas Open, High, Low y Close, evaluando el desempeño 
del modelo mediante cinco métricas de error: MSE, MAE, RSE, RAE y el 
Coeficiente de Correlación.

El objetivo principal es verificar la capacidad predictiva del modelo 
utilizando los valores del período anterior como variables independientes, 
lo que representa un escenario más realista y evita el sobreajuste que 
ocurriría al utilizar variables del mismo instante de tiempo.

\subsection{Algoritmos de regresión}
Los algoritmos de regresión son métodos estadísticos que tratan de determinar la relación entre una variable dependiente —usualmente denominada $Y$— y una serie de otras variables conocidas como variables independientes. 
Los algoritmos de regresión modelan la relación entre las variables, la cual es iterativamente mejorada utilizando métricas de error en la predicción que realiza el modelo.

Los algoritmos de regresión más populares son:

\begin{itemize}
    \item \textbf{Regresión Lineal}: Es un modelo estadístico simple que asume una relación lineal entre la variable independiente $X$ y la dependiente $Y$. La regresión lineal es fácil de interpretar y rápida de entrenar; así mismo, tiene un menor requerimiento computacional.
    \item \textbf{Regresión Polinomial}: Esta regresión es una extensión de la regresión lineal que utiliza potencias de las variables independientes para capturar relaciones no lineales.
    \item \textbf{Regresión Ridge y LASSO}: Estos son tipos de regresión lineal que incluyen regularización para prevenir el sobreajuste. En el caso de la regresión \textbf{Ridge (L2)}, se penaliza la magnitud de los coeficientes, mientras que la regresión \textbf{Lasso (L1)} reduce algunos coeficientes a cero, lo que permite realizar una selección de características.
\end{itemize}

\cite{De0a100enIA_2}

\subsection{Métricas de Error}
Las métricas de evaluación para datos continuos resultan útiles para conocer si los valores aproximados o predichos por un modelo se acercan a los valores reales. Esta diferencia entre los valores reales y los predichos es el error. 

Cada métrica que se comentará a continuación trata este error de manera singular, aplicando diversas ecuaciones que son convenientes para distintos modelos. A continuación, mencionaremos algunas métricas que pueden utilizarse:
\begin{enumerate}
    \item Error Medio Cuadrático (MSE)
    \item Error Medio Absoluto (MAE)
    \item Error Relativo Cuadrático (RSE)
    \item Error Relativo Absoluto (RAE)
    \item Coeficiente de Correlación (CC)
\end{enumerate}
\cite{De0a100enIA}

\subsubsection{Mean Squared Error (MSE y RMSE)}
MSE es comúnmente el método más utilizado para predecir el error. También se utiliza su raíz cuadrada, llamada <<Root Mean Squared Error>> (RMSE). 
Si consideramos el valor real (actual) como $y_i$ y el valor predicho como $\hat{y}_i$, el MSE y el RMSE se calculan como el promedio de la diferencia al cuadrado entre el valor actual y el predicho de la siguiente manera:

\begin{equation}
    MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
\end{equation}
\begin{equation}
    RMSE = \sqrt{\frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2}
\end{equation}

Donde:
\begin{itemize}
    \item $y_i$ = valor real
    \item $\hat{y}_i$ = valor predicho
    \item $n$ = número de observaciones
\end{itemize}

El error medio cuadrático permite evaluar el rendimiento de múltiples modelos en un problema de predicción con datos continuos. El MSE varía en un rango de $[0, \infty)$; un menor valor indica un mejor rendimiento del modelo. Este método penaliza más los errores grandes debido al cuadrado. Sin embargo, tiene limitaciones: es sensible a valores atípicos (<<outliers>>) y no proporciona información sobre la dirección del error.

\cite{De0a100enIA}

\subsubsection{Mean Absolute Error (MAE)}
Es una medida que promedia las magnitudes de cada error de manera individual sin tener en cuenta su signo. Tiene una ventaja con respecto al MSE: con el MAE los \textit{outliers} no son exagerados y se tratan todos los errores por igual de acuerdo a su magnitud.
\begin{equation}
    MAE = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i|
\end{equation}

\cite{De0a100enIA}

\subsubsection{Relative Squared Error (RSE)}
Con el Error Relativo Cuadrático (RSE) se normaliza el error, lo cual permite una comparación entre diferentes conjuntos de datos independientemente de su escala. La desventaja de este método es que es menos intuitivo que el MSE o MAE y requiere calcular la media de los datos reales.
\begin{equation}
    RSE = \frac{\sum_{i=1}^{n} (y_i - \hat{y}_i)^2}{\sum_{i=1}^{n} (y_i - \bar{y})^2} 
\end{equation}
Donde:
\begin{itemize}
    \item $y_i$ = valor real de la observación 
    \item $\hat{y}_i$ = valor predicho de la observación 
    \item $\bar{y}$ = media de los valores reales: $\bar{y} = \frac{1}{n} \sum_{i=1}^{n} y_i$
\end{itemize}
\cite{De0a100enIA}

\subsubsection{Relative Absolute Error (RAE)}
El Error Relativo Absoluto (RAE) es el valor del error absoluto normalizado. A diferencia del MAE, el RAE permite comparar modelos en diferentes escalas.
\begin{equation}
    RAE = \frac{\sum_{i=1}^{n} | y_i - \hat{y}_i |}{\sum_{i=1}^{n} | y_i - \bar{y} |}
\end{equation}
\cite{De0a100enIA}

\subsubsection{Correlation Coefficient (CC)}
Mide la correlación estadística entre los valores actuales y los predichos. Varía entre -1 y 1, donde 1 indica una correlación perfecta. Como desventaja, no indica la magnitud del error y puede ser alto incluso con predicciones sesgadas. 

\begin{equation}
    CC = \frac{\sum_{i=1}^{n} (y_i - \bar{y})(\hat{y}_i - \bar{\hat{y}})}{\sqrt{\sum_{i=1}^{n} (y_i - \bar{y})^2 \cdot \sum_{i=1}^{n} (\hat{y}_i - \bar{\hat{y}})^2}}
\end{equation}

\subsubsection{Coeficiente de determinación (\texorpdfstring{$R^2$}{R2})}
Indica qué proporción de la varianza en los datos reales es explicada por el modelo. Su ecuación es:
\begin{equation}
    R^2 = 1 - \frac{\sum_{i=1}^{n} (y_i - \hat{y}_i)^2}{\sum_{i=1}^{n} (y_i - \bar{y})^2}
\end{equation}

Donde: 
\begin{itemize}
    \item $y_i$ = valor $i$-ésimo real
    \item $\hat{y}_i$ = valor predicho $i$-ésimo
    \item $\bar{y}$ = media de los valores reales
    \item $\bar{\hat{y}}$ = media de los valores predichos
\end{itemize}

\cite{De0a100enIA}

\section{Conclusión}
El modelo de Regresión Lineal demostró un desempeño muy satisfactorio 
para la predicción de precios horarios de la acción de Intel Corporation 
(INTC) durante el período analizado. Los resultados obtenidos confirman 
que existe una alta correlación entre los valores de un período y el 
siguiente, lo cual es característico de series de tiempo financieras 
con alta autocorrelación.

Entre las columnas analizadas, Open resultó ser la mejor predicha con 
un coeficiente de correlación del 99.54\%, lo cual es consistente con 
el hecho de que el precio de apertura de un período está fuertemente 
influenciado por el comportamiento del período inmediatamente anterior. 
Por otro lado, las columnas High y Close presentaron los errores más 
altos, con coeficientes de correlación de 98.40\% y 98.07\% 
respectivamente, lo que se explica porque el precio máximo depende de 
picos momentáneos impredecibles, mientras que Close acumula toda la 
volatilidad generada durante el período.

Un aspecto relevante del análisis fue la decisión de utilizar los datos 
del período anterior mediante la función \texttt{shift(1)} como variables 
independientes, en lugar de utilizar las columnas del mismo instante de 
tiempo. Esta decisión evitó un escenario de sobreajuste donde el modelo 
aprendía una relación matemática casi perfecta entre variables del mismo 
período, logrando así una evaluación más honesta y realista de la capacidad 
predictiva del modelo.

No obstante, es importante reconocer las limitaciones del modelo. La 
Regresión Lineal asume una relación lineal entre las variables, lo cual 
no siempre se cumple en mercados financieros, especialmente en períodos 
de alta volatilidad o ante eventos externos como noticias corporativas 
o decisiones macroeconómicas.
